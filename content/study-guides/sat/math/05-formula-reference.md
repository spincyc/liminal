Two lists. The first is what Bluebook hands you on screen. The second — much
longer, and more important — is what it doesn't.

## Part 2: NOT provided — memorize these

This is the list that matters. Everything below appears on the SAT and is not
handed to you.

### Lines

```
Slope:                m = (y₂ − y₁)/(x₂ − x₁)
Slope-intercept:      y = mx + b
Point-slope:          y − y₁ = m(x − x₁)
Standard:             Ax + By = C

Parallel:             m₁ = m₂
Perpendicular:        m₁ · m₂ = −1

Distance:             d = √[(x₂ − x₁)² + (y₂ − y₁)²]
Midpoint:             ( (x₁+x₂)/2 , (y₁+y₂)/2 )
```

The **distance and midpoint formulas are not on the sheet** and are regularly
needed.

### Quadratics

```
Standard:             y = ax² + bx + c
Factored:             y = a(x − r₁)(x − r₂)
Vertex form:          y = a(x − h)² + k        vertex (h, k)

Quadratic formula:    x = [−b ± √(b² − 4ac)] / (2a)
Discriminant:         D = b² − 4ac
    D > 0  two real solutions
    D = 0  one real solution
    D < 0  no real solutions

Axis of symmetry:     x = −b/(2a)
Sum of roots:         −b/a
Product of roots:      c/a
```

### Factoring

```
a² − b² = (a + b)(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
a³ − b³ = (a − b)(a² + ab + b²)
a³ + b³ = (a + b)(a² − ab + b²)
```

### Exponents and radicals

```
xᵃ · xᵇ = xᵃ⁺ᵇ           xᵃ / xᵇ = xᵃ⁻ᵇ
(xᵃ)ᵇ = xᵃᵇ              (xy)ᵃ = xᵃ yᵃ
x⁰ = 1                   x⁻ᵃ = 1/xᵃ
x^(1/n) = ⁿ√x            x^(m/n) = ⁿ√(xᵐ)

√(ab) = √a · √b          √(a/b) = √a / √b
```

### Exponential growth and decay

```
General:              y = a · bˣ
Growth by rate r:     y = a(1 + r)ᵗ
Decay by rate r:      y = a(1 − r)ᵗ
Compounded n times:   A = P(1 + r/n)^(nt)

a = initial value      b > 1 growth      0 < b < 1 decay
```

### Percentages

```
percent change = (new − old)/old × 100

increase by p%:  × (1 + p/100)
decrease by p%:  × (1 − p/100)
```

### Statistics

```
mean = sum / count
sum  = mean × count

range = max − min

Right-skewed:  mean > median
Left-skewed:   mean < median
Symmetric:     mean ≈ median

More spread → larger standard deviation
Adding a constant to all values: mean shifts, SD unchanged
```

### Probability

```
P(A) = favorable / total
P(not A) = 1 − P(A)
P(A and B) = P(A) · P(B)          [independent]
P(A or B)  = P(A) + P(B) − P(A and B)
P(A | B)   = P(A and B) / P(B)
```

### Geometry — areas not on the sheet

```
Parallelogram:            A = bh
Trapezoid:                A = ½(b₁ + b₂)h
Equilateral triangle:     A = (s²√3)/4
```

### Geometry — surface areas (not on the sheet)

```
Rectangular prism:        SA = 2(lw + lh + wh)
Cylinder:                 SA = 2πr² + 2πrh
Cube:                     SA = 6s²
```

### Circles

```
Standard equation:        (x − h)² + (y − k)² = r²      center (h,k)

Arc length (degrees):     (θ/360) · 2πr
Sector area (degrees):    (θ/360) · πr²
Arc length (radians):     s = rθ
Sector area (radians):    A = ½r²θ

Central angle    = intercepted arc
Inscribed angle  = ½ intercepted arc
Angle in a semicircle = 90°
Tangent ⊥ radius at point of tangency
```

### Angle and polygon facts

```
Sum of interior angles of an n-gon:     (n − 2) · 180°
Each interior angle of a regular n-gon: (n − 2) · 180° / n
Sum of exterior angles (any polygon):   360°
```

### Similar figures

```
Side ratio    k
Area ratio    k²
Volume ratio  k³
```

### Trigonometry

```
sin θ = opp / hyp
cos θ = adj / hyp
tan θ = opp / adj

sin θ = cos(90° − θ)
cos θ = sin(90° − θ)

sin²θ + cos²θ = 1
tan θ = sin θ / cos θ

Radians:  π rad = 180°
          degrees × π/180 = radians
          radians × 180/π = degrees
```

| cos | 1 | √3/2 | √2/2 | 1/2 | 0 |

### Pythagorean triples

```
3-4-5        5-12-13      8-15-17      7-24-25      9-40-41
```
Plus multiples: 6-8-10, 9-12-15, 10-24-26, 15-20-25, 30-40-50.

### Rates and work

```
distance = rate × time
work     = rate × time

Average speed = total distance / total time    (NOT the average of the speeds)
Combined rate = 1/t₁ + 1/t₂ + ...
```

### Sequences

```
Arithmetic:   aₙ = a₁ + (n − 1)d
Geometric:    aₙ = a₁ · r^(n − 1)
```

### Complex numbers

```
i  = √(−1)
i² = −1
i³ = −i
i⁴ = 1        (the cycle repeats every 4)
```

To divide by a complex number, multiply by the conjugate:
`1/(a + bi) × (a − bi)/(a − bi)`.

## The memorize-first shortlist

If you only commit ten things to memory, make it these — they carry the most
weight per item:

1. **Slope formula** and parallel/perpendicular relationships
2. **Distance and midpoint** formulas
3. **Quadratic formula** and what the **discriminant** tells you
4. **Vertex** at `x = −b/(2a)`
5. **Difference of squares** `a² − b² = (a+b)(a−b)`
6. **Exponent rules**, especially fractional exponents
7. **Exponential model** `y = a(1 ± r)ᵗ`
8. **Percent change** with the **original** in the denominator
9. **Circle equation** `(x−h)² + (y−k)² = r²`
10. **`sin θ = cos(90° − θ)`**

## What to do with this file

Do not read it repeatedly. Reading formula lists produces recognition, not
recall.

Instead:

1. **Copy Part 2 by hand, once.** Handwriting a formula list is meaningfully
   better for retention than reading it.
2. **Make cards for anything you couldn't reproduce from memory.**
3. **Blank-page test:** once a week, write out everything you can remember from
   Part 2 without looking. What's missing is your study list.
4. **Drill the formulas in context**, not in isolation. Knowing `D = b² − 4ac`
   is useless if you don't recognize a "how many solutions" question as a
   discriminant question.
