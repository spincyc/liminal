# ACT Reading — Integration of Knowledge and Ideas

**Catalog domain:** Integration of Knowledge and Ideas
**Skills:** Arguments · Multiple Texts · Visual and Quantitative Information
**~24% of the section** — 8-9 questions

Analysis and synthesis: evaluating claims, comparing texts, and reading data
alongside prose.

---

## Arguments

### Question forms

- "Which of the following, if true, would most weaken the author's claim?"
- "The author supports the assertion in lines 20-24 primarily by..."
- "Which of the following best states the author's main argument?"
- "The author's reasoning depends on the assumption that..."

### Argument anatomy

Every argument has three parts. Identify them before answering.

| Part | Question it answers |
| --- | --- |
| **Claim** | What is being asserted? |
| **Evidence** | What supports it? |
| **Assumption** | What must be true for the evidence to support the claim? |

Assumptions are unstated by definition. They're the gap between evidence and
claim.

> *Claim:* the new curriculum improved reading scores.
> *Evidence:* scores rose after it was introduced.
> *Assumption:* nothing else that changed at the same time caused the rise.

Most "weaken" questions attack the assumption.

### Types of evidence

Answers to "how does the author support this?" name the evidence type:

> citing a study · offering an anecdote · quoting an authority · drawing an
> analogy · providing statistics · describing a personal experience ·
> presenting a counterexample · appealing to historical precedent

**Match the type.** If the support was one person's story, the answer is
"anecdote," not "statistical evidence" — even if the anecdote included a number.

### Strengthen and weaken

**Weaken:** find the assumption, then find the choice that breaks it.

Common weakening moves:
- An alternative explanation for the evidence
- A counterexample
- Evidence that the sample was unrepresentative
- Showing the correlation ran the other direction
- Showing the effect existed before the supposed cause

**Strengthen:** the reverse — a choice ruling out an alternative explanation, or
supplying the missing link.

**Pattern:** the credited answer addresses the **specific logic** of this
argument. Distractors are relevant to the topic but don't affect the reasoning.

**Pattern:** on "if true" questions, accept the choice as fact. Don't evaluate
whether it's plausible; evaluate whether it damages the argument.

### Reasoning flaws the ACT tests

| Flaw | Description |
| --- | --- |
| **Correlation → causation** | Two things co-occur; the author claims one causes the other |
| **Unrepresentative sample** | Generalizing from a narrow group |
| **Overgeneralization** | One case → universal claim |
| **Confusing necessary and sufficient** | X is required, so X is enough |
| **False dilemma** | Only two options presented when others exist |
| **Circular reasoning** | The conclusion restated as evidence |

## Multiple Texts (paired passages)

One of the four passage sets is paired: two shorter passages by different
authors on a related subject.

### Question distribution

Roughly: three questions on Passage A, three on Passage B, three comparing.

### Method — the order matters

1. **Read Passage A.** Answer the A-only questions.
2. **Read Passage B.** Answer the B-only questions.
3. **Then** answer the comparison questions.

**Do not read both passages before answering anything.** They blur together, and
confusing which author said what is the dominant error on paired sets.

Before the comparison questions, write or say **one sentence per author** stating
their position.

### Naming the relationship

Before reading comparison choices, name the relationship yourself:

| Relationship | Description |
| --- | --- |
| **Agreement with elaboration** | B extends or details A |
| **Agreement on facts, disagreement on interpretation** | Most common |
| **Direct disagreement** | Less common than students expect |
| **B qualifies A** | Accepts with limits |
| **B offers an alternative explanation** | Same observation, different cause |
| **Different focus** | Related topic, different aspect |

### Question forms and how to attack them

**"Both authors would agree that..."**
Find something **explicitly supported in both**. The credited answer is usually
modest — a shared premise rather than a shared conclusion. Distractors are
supported by one passage only.

**"The author of Passage B would most likely respond to [A's claim] by..."**
Find B's stated principle and apply it directly to A's claim. Don't invent a
response. The credited answer is a direct application, not a creative extension.

**"Which best describes a difference between the passages?"**
The difference must be real and must be about **the asked-about dimension**.
Distractors name a true difference on a different axis (tone instead of
conclusion, scope instead of method).

**"Compared to Passage A, Passage B is more..."**
Comparative claims about tone, specificity, or scope. Check both passages
against the dimension — a choice can be true of B and also true of A, which
makes it wrong.

### Traps

| Trap | Description |
| --- | --- |
| **One-passage answer** | Correct about B, ignores the relationship |
| **Author swap** | Attributed A's view to B |
| **Overstated conflict** | "Refutes" when B merely qualifies |
| **Invented agreement** | Consensus the texts don't establish |
| **Wrong axis** | Real difference, not the one asked about |

## Visual and Quantitative Information

Some passages — most often Natural Science and Social Science — include a chart,
graph, table, or diagram.

### Method

1. **Read the title, axis labels, units, and legend before the question.** Ten
   seconds. This prevents most errors here.
2. Note the **units and any scale prefix** (thousands, millions, percent).
3. Check whether there's a **second y-axis** on the right.
4. Then read the question and locate the specific data.

### Question forms

- "According to the figure, what was the approximate value of [X] in [year]?"
- "The data in the table most strongly support which conclusion?"
- "Based on both the passage and the figure..."
- "Which statement is best supported by the figure?"

### Patterns

**Match direction first.** As X increases, does Y increase or decrease?
Establishing direction alone usually eliminates half the choices.

**Trends beat point values.** When asked what happens generally, the answer
describes the overall pattern. A choice built from one data point — especially
an outlier — is usually a distractor.

**Read only what's asked.** Don't interpret the whole figure; find the specific
value or comparison.

**Comparison language is precise:**

| Phrase | Means |
| --- | --- |
| "greater than" | Absolute comparison at one point |
| "increased more" | Absolute change comparison |
| "increased by a greater percentage" | Relative change — different answer |
| "consistently higher" | True at **every** point |
| "on average higher" | True of the mean, may fail at some points |

"Consistently" is an absolute — one crossing makes it false.

**Combined passage-and-figure questions** require both sources. Verify the
choice against each. A choice accurate to the figure but contradicted by the
passage is wrong, and vice versa.

### Traps

| Trap | Description |
| --- | --- |
| **Wrong series** | Read the wrong line in a multi-line graph |
| **Missed second axis** | Read a right-axis value against the left scale |
| **Unit prefix** | Missed "in thousands" |
| **Legend reversed** | Swapped the two groups |
| **Greatest value vs. greatest increase** | Different questions |
| **Cumulative read as per-period** | |
| **Extrapolation** | Extended a trend beyond the data |
| **Used only one source** | Question required passage *and* figure |

## Drill plan

| Stage | Filter | Volume and method |
| --- | --- | --- |
| 1. Argument anatomy | Arguments, Medium | 20. Write claim / evidence / assumption for each. |
| 2. Strengthen and weaken | Arguments, Medium → Hard | 20. Name the assumption before reading choices. |
| 3. Evidence type | Arguments, Easy → Medium | 15. Name the support type in one word. |
| 4. Paired passages | Multiple Texts, Medium → Hard | 20. **Write one sentence per author** every time. |
| 5. Figures | Visual and Quantitative Information, Medium | 25. Narrate title, axes, units, legend aloud before answering. |
| 6. Mixed timed | Whole domain | Two passage sets at 10 min each |

Stage 4's one-sentence-per-author habit is the single fix for paired passages.
Almost every miss on these traces back to losing track of who said what.

Stage 5's ten-second orientation habit is worth more than any interpretive
skill. Most figure errors are reading errors, not reasoning errors.
