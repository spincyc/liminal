# ACT English — Production of Writing

**Catalog domain:** Production of Writing
**Skills:** Topic Development · Organization, Unity, and Cohesion
**~41% of the section** — about 20 questions

The largest domain on ACT English. These are the rhetorical questions: what
belongs, where it goes, and how the pieces connect. They take longer than
grammar questions and they're where the section's difficulty lives.

---

## Topic Development

Questions about whether material serves the writer's purpose.

### Question forms

| Form | What it asks |
| --- | --- |
| "Which choice most effectively [stated goal]?" | Does this accomplish the goal |
| "The writer is considering deleting... Should it be kept or deleted?" | Is this material necessary |
| "At this point the writer wants to add [X]. Would this be a relevant addition?" | Is this on-topic |
| "Which choice provides the most specific detail?" | Concreteness |
| "Suppose the writer's goal had been to [X]. Would this essay accomplish it?" | Whole-essay purpose |

### The stated goal is the entire rubric

When the question names a goal, that goal is the grading criterion — the *only*
criterion.

> *"Which choice most effectively emphasizes the difficulty of the climb?"*

A choice can be more elegant, more vivid, and better written, and still be wrong
because it doesn't emphasize difficulty. Reread the goal after narrowing to two.
This resolves most of these immediately.

**Method:**

1. Read the goal. **Underline the key word** — *emphasize*, *contrast*,
   *introduce*, *specific*, *conclude*.
2. Parse it into requirements. Many goals have two parts.
3. Check each choice against each requirement as a checklist.
4. Ignore style. Only the goal counts.

### Keep-or-delete questions

The answer choices come in two halves: **Kept/Deleted**, and a **reason**. You
must get both right.

**Method:**

1. Read the sentence in question.
2. Read the sentences before and after.
3. Decide: does it serve the paragraph's point?
4. **Then check the reason.** A choice with the right verdict and a false reason
   is wrong.

**Delete when the material:**
- Repeats something already stated
- Is irrelevant to the paragraph's topic
- Is an interesting aside that breaks the flow
- Contradicts the passage

**Keep when the material:**
- Provides necessary information for what follows
- Supplies a needed transition
- Gives a specific example supporting the paragraph's claim
- Defines a term the reader needs

**Pattern:** the reason halves are where these are lost. Common false reasons:

| False reason type | Example |
| --- | --- |
| Claims info appears elsewhere when it doesn't | "because this is stated in paragraph 2" |
| Claims relevance to a topic the passage doesn't cover | "because it explains the author's motivation" |
| Right verdict, invented justification | "because it provides a transition" when it doesn't |

Verify the reason against the text, every time.

### "Would this be a relevant addition?"

**The answer is often no.** The proposed sentence is usually related to the
general topic but not to *this paragraph's* specific point.

Test: does the addition support the sentence immediately before or after it? If
it merely mentions the same subject matter, that's not relevance.

### "Most specific detail" questions

The credited answer contains **concrete, verifiable specifics**: numbers, names,
measurable descriptions, dates.

| Vague | Specific |
| --- | --- |
| "a long time" | "eleven years" |
| "very large" | "forty feet across" |
| "some scientists" | "researchers at the Scripps Institution" |
| "improved a lot" | "doubled between 1990 and 2005" |

This is one of the few places on ACT English where **longer is often better**.
The shortest-answer principle doesn't apply when the goal explicitly asks for
detail.

### Whole-essay questions

Usually the last question for a passage:

> *"Suppose the writer's goal had been to write an essay describing the process
> by which glass is recycled. Would this essay accomplish that goal?"*

**Method:** ask what the essay was *actually* about. If the essay was a personal
narrative about visiting a recycling plant, then no — it doesn't *describe the
process*.

Then check the reason half, same as keep-or-delete.

**Pattern:** the verdict is usually determined by a *scope* mismatch. The essay
covers something adjacent to the stated goal — one example instead of a general
process, one person's experience instead of a history.

## Organization, Unity, and Cohesion

Questions about order and connection.

### Transitions

The most common question type in this skill. Same method as everywhere:

1. **Cover the choices.**
2. Read the sentence **before**. Summarize.
3. Read the sentence **after**. Summarize.
4. **Name the relationship** yourself.
5. Then find the matching transition.

Reading the choices first is how these are lost. Transitions rarely create
grammatical problems, so every option "sounds fine" — you must evaluate on
logic, and that requires a prediction.

**The relationship groups:**

| Relationship | Words |
| --- | --- |
| Addition | also, moreover, furthermore, in addition, similarly |
| Contrast | however, but, nevertheless, on the other hand, conversely, still, yet |
| Cause → effect | therefore, thus, consequently, as a result, hence, so |
| Effect → cause | because, since, after all |
| Example | for example, for instance, specifically, in particular |
| Emphasis | indeed, in fact, certainly |
| Concession | admittedly, granted, of course, to be sure |
| Sequence | first, next, then, meanwhile, later, finally |
| Conclusion | in conclusion, ultimately, in short, overall |

**Distinctions that get tested:** *however* vs. *therefore* (opposite
directions), *for example* vs. *in contrast*, *indeed* vs. *however*,
*nevertheless* vs. *consequently*, *meanwhile* vs. *therefore*.

**Note:** "DELETE the underlined portion" is often offered on transition
questions, and is sometimes correct — when no transition is needed because the
sentences simply continue.

### Sentence placement

> *"For the sake of the logic and coherence of this paragraph, Sentence 4 should
> be placed..."*

**Method:**

1. Read the sentence being moved. **Find its pronouns, transitions, and
   references** — *this*, *these*, *such*, *the aforementioned*, *also*, *he*,
   *it*.
2. Those words point backward. Whatever they refer to must come **immediately
   before**.
3. Also check what must come **after**: does a later sentence depend on this
   one?

**Pattern:** the answer is almost always determined by a **reference chain**. A
sentence beginning "This process..." must follow a sentence that describes a
process. A sentence introducing a person by full name must come before one
referring to them by last name only.

**Chronology** is the other common organizing logic. If the paragraph narrates
events, order by time.

### Paragraph placement

Same logic at a larger scale.

1. What does this paragraph introduce, and what does it assume you already know?
2. Find the paragraph that supplies what it assumes.
3. Check the opening sentence for backward-pointing words.

Also consider structure: introductions establish context, conclusions
generalize. A paragraph that begins "But the most significant obstacle was..."
must follow discussion of other obstacles.

### Opening and closing sentences

> *"Which choice provides the most effective introduction to the paragraph?"*

**For an opening:** the credited sentence introduces what the paragraph
*actually goes on to discuss*. Read the rest of the paragraph first, then pick
the sentence that sets it up. Distractors introduce a topic the paragraph
doesn't develop.

**For a closing:** the credited sentence wraps up the paragraph's point or
transitions to the next. Distractors introduce new information — a conclusion
that raises a new topic is wrong.

**For an essay conclusion:** it should echo the essay's main idea, not a single
detail.

### Cohesion

Questions about whether pieces connect logically. Look for:

- **Pronoun reference chains** — does *this*, *they*, *it* have a clear
  antecedent in the previous sentence?
- **Repeated key terms** binding sentences together
- **Consistent subject focus** — paragraphs that keep the same grammatical
  subject read as more cohesive

## Patterns and tells

**On any goal-stated question, the goal is the answer key.** Reread it before
selecting.

**Distractors are usually well-written.** Quality of prose is not the
discriminator on this domain; *fit to the stated job* is.

**"Would this be a relevant addition?" → usually no.**

**Keep-or-delete: check the reason half separately.** Half the wrong answers
have the correct verdict.

**On placement questions, follow the pronouns.** Backward-pointing words
determine the order almost every time.

**On transitions, contrast is over-represented** — but only guess that as a last
resort, after actually determining the relationship.

**Specificity questions are the exception to "shorter is better."**

## Traps

| Trap | Description |
| --- | --- |
| **Best-sounding sentence** | Picked elegance over the stated goal |
| **Half the goal** | Two-part goal, choice satisfies one part |
| **Right verdict, false reason** | Correct keep/delete, invented justification |
| **On-topic but off-point** | Related to the subject, not to this paragraph |
| **Transition by ear** | Chose one that "sounds academic" without checking logic |
| **Reversed causation** | `Therefore` where `because` was needed |
| **New info in a conclusion** | Closing sentence that opens a new topic |
| **Ignored the pronoun chain** | Placed a sentence before its referent |

## Drill plan

| Stage | Filter | Volume and method |
| --- | --- | --- |
| 1. Transitions | Organization, Unity, and Cohesion, Easy → Medium | 30. **Cover the choices; name the relationship aloud** for the first 20. |
| 2. Keep/delete | Topic Development, Medium | 25. Write the verdict, *then* check the reason. |
| 3. Goal-stated questions | Topic Development, Medium → Hard | 25. Underline the goal and list its requirements. |
| 4. Placement | Organization, Unity, and Cohesion, Medium → Hard | 20. Circle every backward-pointing word. |
| 5. Whole-essay | Topic Development, Hard | 10 |
| 6. Mixed timed | Whole domain | 40 at 50 sec each |

Note the timing target in stage 6: rhetorical questions get 50 seconds because
grammar questions should be taking you 20. The budget only works if the
mechanical half is fast.
