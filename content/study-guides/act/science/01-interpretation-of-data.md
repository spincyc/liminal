# ACT Science — Interpretation of Data

**Catalog domain:** Interpretation of Data
**Skills:** Read data displays · Analyze data · Translate data
**~44% of the section** — 17-18 questions

The largest domain. Pure figure reading, and the most mechanical skill on either
test. Also the fastest to improve.

---

## Read data displays

Locating and reading specific values.

### Question forms

- "According to Figure 1, at 40 °C the reaction rate was approximately..."
- "Based on Table 2, which sample had the highest density?"
- "In Study 1, the concentration of X after 6 hours was closest to..."

### Method

1. **Identify the figure** the question names. If it names none, find the one
   containing the variables mentioned.
2. **Orient:** title, axes, units, legend, scale, second axis.
3. **Locate** the specified condition on the appropriate axis.
4. **Trace** to the curve or bar, then across to the value.
5. **Check the unit** against what the question asked for.

### The orientation checklist

Ten seconds, every figure:

| Check | Why |
| --- | --- |
| **Title** | Tells you what's being measured |
| **X-axis label and units** | |
| **Y-axis label and units** | |
| **Second y-axis?** | On the right side — the most missed feature |
| **Legend** | Which line is which |
| **Scale type** | Linear or logarithmic |
| **Does the axis start at zero?** | A truncated axis exaggerates differences |
| **Unit prefix** | "thousands," "×10⁻³," "per 100,000" |

**Half of all errors in this domain are orientation errors.** Not reasoning
errors — reading errors. This checklist is the fix.

### Reading between gridlines

Many questions require estimating between marked values. That's expected.

- Determine what one gridline interval represents
- Estimate the fraction of an interval
- **Answer choices are usually spread widely enough** that a rough estimate
  suffices

If two choices are very close together, reread — you may have the wrong series
or the wrong axis.

### Tables

Tables are usually easier than graphs, but easier to misread under time
pressure.

- **Trace with your finger or cursor** across the row and down the column
- Watch for **units in the column header** rather than in each cell
- Watch for **footnotes**

## Analyze data

Identifying trends, relationships, and comparisons.

### Question forms

- "As temperature increased, the rate of reaction..."
- "Which of the following best describes the relationship between X and Y?"
- "Based on Figure 2, as pressure increases, volume..."
- "For which sample did the value change the most between trials?"

### Method — direction first

1. Look at the leftmost part of the curve and the rightmost part.
2. **Does it go up or down?**
3. That alone usually eliminates half the choices.
4. Then refine: is it linear, accelerating, decelerating, or does it reverse?

### Trend vocabulary

| Description | Shape |
| --- | --- |
| **Directly proportional** | Straight line through the origin; doubling one doubles the other |
| **Inversely proportional** | Hyperbola; doubling one halves the other |
| **Linear increase** | Straight line up |
| **Exponential increase** | Curve steepening upward |
| **Levels off / plateaus** | Rises then flattens |
| **Peaks** | Rises then falls |
| **No relationship** | Scattered, flat, or random |

**"Directly proportional" is stronger than "increases."** A line that increases
but doesn't pass through the origin is not directly proportional. The ACT tests
this distinction.

### Comparison precision

| Phrase | Means |
| --- | --- |
| "greater than" | At one specific point |
| "increased more" | Absolute change |
| "increased by a greater percentage" | Relative change |
| "consistently higher" | True at **every** point |
| "on average higher" | True of the mean |
| "the greatest value" | Highest single reading |
| "the greatest increase" | Largest change — different question |

**"Greatest value" vs. "greatest increase" is a recurring trap.** A series can
have the highest values throughout while another has the steepest rise.

### Trends beat points

When asked what happens *generally*, the answer describes the pattern. A choice
built from one data point — especially an outlier — is a distractor.

Conversely, when asked about a *specific* condition, don't generalize. Read that
point.

## Translate data

Converting between representations, and combining figures.

### Question forms

- "Which graph best represents the data in Table 1?"
- "Based on Table 1 and Figure 2, what was the value of X when Y was 30?"
- "If the data in Figure 1 were plotted as a bar graph, which would result?"

### Graph-matching questions

> "Which of the following graphs best represents the relationship shown?"

**Method — check three things:**

1. **Direction** — up or down? Eliminates half.
2. **Shape** — linear, curved, plateauing, peaked?
3. **One specific point** — pick an easy value from the data and check that the
   graph passes through it.

That third check resolves nearly every remaining ambiguity.

### Two-figure questions

The most-missed type in this domain.

> "Based on Table 1 and Figure 2, the density of Sample C at 50 °C was..."

**Method:**

1. Identify the **linking variable** — the quantity appearing in both figures.
2. Use the first figure to find the linking value.
3. Use that value to enter the second figure.
4. Read the final answer.

**Write the intermediate value down.** The most common failure here is finding
the linking value correctly and then losing it while switching figures.

### Interpolation and extrapolation

**Interpolation** — estimating *between* data points. Generally reliable.

**Extrapolation** — estimating *beyond* the data. The ACT asks for it, but:
- Continue the existing trend
- Don't assume the trend continues indefinitely if the data show it leveling off
- Questions asking which prediction is *least* reliable are answered by
  whichever is furthest outside the observed range

## Patterns and tells

**Orient before reading. Always.**

**Direction first, precision second.**

**When two answer choices are very close**, you're probably on the wrong series
or the wrong axis. Recheck orientation rather than squinting harder.

**Answers should be physically plausible.** A negative concentration or a
percentage over 100 is a signal you misread something.

**If a question names two figures, you need both.** Don't answer from one.

**Match the unit the question asks for.** If the axis is in grams and the
question asks for milligrams, convert.

## Traps

| Trap | Description |
| --- | --- |
| **Wrong series** | Read the wrong line or bar |
| **Second axis** | Used the left scale for a right-axis value |
| **Legend reversed** | Swapped the groups |
| **Unit prefix** | Missed "in thousands" |
| **Log scale read as linear** | |
| **Truncated axis** | Overstated a difference because the axis doesn't start at zero |
| **Value vs. change** | Answered "greatest value" when "greatest increase" was asked |
| **Outlier as trend** | Built the answer from one anomalous point |
| **Lost the intermediate value** | On a two-figure question |
| **"Directly proportional" loosely** | Used it for any increasing relationship |

## Drill plan

| Stage | Filter | Volume and method |
| --- | --- | --- |
| 1. Orientation | Read data displays, Easy | 30. **Narrate title, axes, units, legend aloud** before every question. |
| 2. Value reading | Read data displays, Easy → Medium | 30, untimed for accuracy |
| 3. Trends | Analyze data, Medium | 30. State direction before looking at choices. |
| 4. Comparisons | Analyze data, Medium → Hard | 25. Note exactly which comparison word is used. |
| 5. Two-figure | Translate data, Medium → Hard | 25. **Write the intermediate value down** every time. |
| 6. Graph matching | Translate data, Medium | 15. Direction, shape, one point. |
| 7. Timed | Whole domain | 3 full passages at 5 min each |

Stage 1 is the highest-yield hour you will spend on ACT Science. The narration
feels silly and it eliminates most of your errors. After about 30 items it
becomes automatic and you can stop narrating aloud.
