# ACT Science — Interpretation of Data

**Catalog domain:** Interpretation of Data
**Skills:** Read data displays · Analyze data · Translate data
**38–50% of scored Science questions** — 13–17 of 34; see the
[overview](00-overview.md) for the official blueprint source.

This domain includes reading, analyzing and translating data. Practice both
accurate figure reading and the reasoning needed to interpret patterns.

---

## Read data displays

Locating and reading specific values.

### Question forms

- "According to Figure 1, at 40 °C the reaction rate was approximately..."
- "Based on Table 2, which sample had the highest density?"
- "In Study 1, the concentration of X after 6 hours was closest to..."

### Method

1. **Identify the figure** the question names. If it names none, find the one
   containing the variables mentioned.
2. **Orient:** title, axes, units, legend, scale, second axis.
3. **Locate** the specified condition on the appropriate axis.
4. **Trace** to the curve or bar, then across to the value.
5. **Check the unit** against what the question asked for.

### The orientation checklist

Ten seconds, every figure:

| Check | Why |
| --- | --- |
| **Title** | Tells you what's being measured |
| **X-axis label and units** | |
| **Y-axis label and units** | |
| **Second y-axis?** | On the right side — the most missed feature |
| **Legend** | Which line is which |
| **Scale type** | Linear or logarithmic |
| **Does the axis start at zero?** | A cropped axis can exaggerate the apparent relative difference; use its labels |
| **Unit prefix** | "thousands," "×10⁻³," "per 100,000" |

Orientation errors can be prevented by this checklist. Check your error log
to distinguish them from missing concepts, reasoning errors and time pressure.

### Reading between gridlines

Many questions require estimating between marked values. That's expected.

- Determine what one gridline interval represents
- Estimate the fraction of an interval
- **Answer choices are usually spread widely enough** that a rough estimate
  suffices

If two choices are very close together, reread — you may have the wrong series
or the wrong axis. If the series and axis are correct, use the stated precision
and the nearest labeled values; closeness alone does not establish a reading
mistake.

> **Worked example: scale and legend.** A graph's horizontal axis marks
> time at 0, 4 and 8 minutes, with four equal grid intervals between 0 and 4.
> The left vertical axis marks concentration in `×10⁻³ g/mL` at 2, 4 and 6.
> The legend assigns circles to Sample A and triangles to Sample B. At
> 5 minutes, B's triangle is halfway between vertical values 4 and 6.
> What concentration does it show?
>
> Each horizontal interval is 1 minute, so use the triangle one interval
> after 4. Its vertical coordinate is 5 model units, which means
> `5 × 10⁻³ = 0.005 g/mL`. Reading Sample A, treating an interval as
> 4 minutes, or dropping the `10⁻³` gives a different answer.

**Two vertical axes:** identify which scale belongs to each series. A
temperature curve and a concentration curve can appear to cross while using
different units and scales. That visual crossing does not mean their measured
quantities are equal.

**Logarithmic axes:** equally spaced labels such as 1, 10 and 100 indicate
equal factors, not equal differences. Halfway between 10 and 100 on a base-10
log axis is about 32, not 55. Use the stated scale; the usual linear
interpolation rule cannot be applied to its drawn distances.

### Tables

Tables are usually easier than graphs, but easier to misread under time
pressure.

- **Trace with your finger or cursor** across the row and down the column
- Watch for **units in the column header** rather than in each cell
- Watch for **footnotes**

## Analyze data

Identifying trends, relationships, and comparisons.

### Question forms

- "As temperature increased, the rate of reaction..."
- "Which of the following best describes the relationship between X and Y?"
- "Based on Figure 2, as pressure increases, volume..."
- "For which sample did the value change the most between trials?"

### Method — direction first

1. Locate the interval and series the question names.
2. Compare its starting and ending values for the overall change.
3. Trace the points between them: does the trend reverse or level off?
4. Distinguish the value from the rate of change using the axis units.

Comparing endpoints is a useful first pass. **It fails when the claim is
"increased throughout" or "remained constant":** identical endpoints can hide
a rise and fall, and a positive net change can include a decrease.

### Trend vocabulary

The shapes below assume ordinary linear axes. On logarithmic axes, check the
labels before using shape to classify a relationship.

| Description | Shape |
| --- | --- |
| **Directly proportional** | Straight line through the origin; doubling one doubles the other |
| **Inversely proportional** | Hyperbola; doubling one halves the other |
| **Linear increase** | Straight line up |
| **Exponential increase** | For positive outputs, equal input steps multiply output by the same factor greater than 1; shape alone is insufficient |
| **Levels off / plateaus** | Rises then flattens |
| **Peaks** | Rises then falls |
| **Constant response** | Horizontal line: output does not change across the shown inputs |
| **No clear association** | Scatter without a discernible pattern; this does not prove no relationship exists |

**"Directly proportional" is stronger than "increases."** A line that increases
but doesn't pass through the origin is not directly proportional. The ACT tests
this distinction.

### Comparison precision

| Phrase | Means |
| --- | --- |
| "greater than" | At one specific point |
| "increased more" | Absolute change |
| "increased by a greater percentage" | Relative change |
| "consistently higher" | True at **every** point |
| "on average higher" | True of the mean |
| "the greatest value" | Highest single reading |
| "the greatest increase" | Largest change — different question |

**"Greatest value" vs. "greatest increase" is a recurring trap.** A series can
have the highest values throughout while another has the steepest rise.

> **Worked example: change versus rate.** An experiment records gas volume
> at `(time in seconds, volume in mL)` points `(0, 4)`, `(2, 10)`, `(6, 18)`
> and `(8, 16)`. Over which adjacent recorded interval is the average rate
> of increase greatest?
>
> From 0 to 2 seconds: `(10 − 4)/2 = 3 mL/s`. From 2 to 6:
> `(18 − 10)/4 = 2 mL/s`. From 6 to 8: `(16 − 18)/2 = −1 mL/s`.
> The greatest rate is in the first interval. The second interval has
> the largest absolute increase, 8 mL, but takes twice as long.
> The volume increases overall from 4 to 16 mL, yet decreases after
> 6 seconds, so "increased throughout" is false.

A steeper segment means a greater magnitude of rate only after accounting
for axis scales and units. It does not mean a greater output. A rising
curve that flattens still increases, but its rate of increase decreases.

### Trends beat points

When asked what happens *generally*, the answer describes the pattern. A choice
built from one data point — especially an outlier — is a distractor.

Conversely, when asked about a *specific* condition, don't generalize. Read that
point.

## Translate data

Converting between representations, and combining figures.

### Question forms

- "Which graph best represents the data in Table 1?"
- "Based on Table 1 and Figure 2, what was the value of X when Y was 30?"
- "If the data in Figure 1 were plotted as a bar graph, which would result?"

### Graph-matching questions

> "Which of the following graphs best represents the relationship shown?"

**Method — check three things:**

1. **Direction** — up, down, constant, or changing direction?
2. **Shape** — linear, curved, plateauing, peaked?
3. **One specific point** — pick an easy value from the data and check that the
   graph passes through it.

These checks can eliminate candidates quickly. **They fail to settle the
choice when multiple graphs share those features.** Check another point,
the intercepts, axis scales and any turning point. Do not connect independent
categories merely because their bars are adjacent.

### Two-figure questions

The most-missed type in this domain.

> "Based on Table 1 and Figure 2, the density of Sample C at 50 °C was..."

**Method:**

1. Identify the **linking variable** — the quantity appearing in both figures.
2. Use the first figure to find the linking value.
3. Use that value to enter the second figure.
4. Read the final answer.

**Write the intermediate value down.** The most common failure here is finding
the linking value correctly and then losing it while switching figures.

> **Worked example: connect displays.** Table 1 says that Sample C was
> measured at 30 °C. A calibration graph gives density 1.08 g/mL at 20 °C
> and 1.04 g/mL at 40 °C, with a straight segment joining them. What density
> does that segment estimate for Sample C?
>
> The linking quantity is temperature, not the sample's letter. Enter the
> graph at 30 °C, halfway from 20 to 40. The estimated density is halfway
> from 1.08 to 1.04: `1.06 g/mL`. The estimate uses the stated straight
> segment; it is not a new measurement.

Check whether the displays share the same sample, treatment and conditions
before combining them. A temperature-to-density graph for one liquid does not
automatically describe another liquid.

### Interpolation and extrapolation

**Interpolation** — estimating *between* data points. Use the displayed or
stated model. It can still be uncertain across a wide gap or a sharp change.

**Extrapolation** — estimating *beyond* the data. The ACT asks for it, but:
- Continue the trend only under the question's stated model or assumption
- Don't assume the trend continues indefinitely if the data show it leveling off
- A prediction far outside the observed range is often less supported, but
  distance alone is not a universal ranking rule: changed conditions and
  model limits also matter

## Patterns and tells

**Orient before reading. Always.**

**Direction first, precision second.**

**When two answer choices are very close**, recheck the series, axis and unit,
then read at the precision the question requests.

**Check physical meaning.** An ordinary concentration cannot be negative, but
a change in concentration can be. A percent of a whole cannot exceed 100%,
but a percent increase can. Plausibility checks depend on what is measured.

**If a question names two figures, you need both.** Don't answer from one.

**Match the unit the question asks for.** If the axis is in grams and the
question asks for milligrams, convert.

## Traps

| Trap | Description |
| --- | --- |
| **Wrong series** | Read the wrong line or bar |
| **Second axis** | Used the left scale for a right-axis value |
| **Legend reversed** | Swapped the groups |
| **Unit prefix** | Missed "in thousands" |
| **Log scale read as linear** | |
| **Truncated axis** | Overstated a difference because the axis doesn't start at zero |
| **Value vs. change** | Answered "greatest value" when "greatest increase" was asked |
| **Outlier as trend** | Built the answer from one anomalous point |
| **Lost the intermediate value** | On a two-figure question |
| **"Directly proportional" loosely** | Used it for any increasing relationship |
