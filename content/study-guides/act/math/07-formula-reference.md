# ACT Mathematics — Formula Reference

**The ACT provides no formula sheet.** Everything below must be in your head.

This is the most important memorization document for the ACT. Handwrite it once,
then run weekly blank-page recall tests.

---

## Lines and coordinate geometry

```
Slope:                m = (y₂ − y₁)/(x₂ − x₁)
Slope-intercept:      y = mx + b
Point-slope:          y − y₁ = m(x − x₁)
Standard:             Ax + By = C

Parallel:             m₁ = m₂
Perpendicular:        m₁ · m₂ = −1

Distance:             d = √[(x₂−x₁)² + (y₂−y₁)²]
Midpoint:             ((x₁+x₂)/2, (y₁+y₂)/2)
```

### Conic recognition

```
Circle:      (x−h)² + (y−k)² = r²
Parabola:    y = a(x−h)² + k
Ellipse:     (x−h)²/a² + (y−k)²/b² = 1
Hyperbola:   (x−h)²/a² − (y−k)²/b² = 1
```

### Coordinate transformations

```
Reflect over x-axis:        (x, y) → (x, −y)
Reflect over y-axis:        (x, y) → (−x, y)
Reflect over y = x:         (x, y) → (y, x)
Rotate 90° CCW about origin: (x, y) → (−y, x)
Rotate 180° about origin:    (x, y) → (−x, −y)
Translate by (a, b):        (x, y) → (x+a, y+b)
```

## Algebra

```
Quadratic formula:    x = [−b ± √(b² − 4ac)]/(2a)
Discriminant:         D = b² − 4ac
    D > 0  two real     D = 0  one real     D < 0  none real

Vertex:               x = −b/(2a)
Vertex form:          y = a(x − h)² + k
Sum of roots:         −b/a
Product of roots:      c/a
```

### Factoring

```
a² − b² = (a + b)(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
a³ − b³ = (a − b)(a² + ab + b²)
a³ + b³ = (a + b)(a² − ab + b²)
```

### Exponents and radicals

```
xᵃ · xᵇ = xᵃ⁺ᵇ         xᵃ/xᵇ = xᵃ⁻ᵇ
(xᵃ)ᵇ = xᵃᵇ            (xy)ᵃ = xᵃyᵃ
x⁰ = 1                 x⁻ᵃ = 1/xᵃ
x^(1/n) = ⁿ√x          x^(m/n) = ⁿ√(xᵐ)

√(ab) = √a·√b          √(a/b) = √a/√b
```

### Logarithms

```
log_b(x) = y  ⟺  bʸ = x

log(mn)  = log m + log n
log(m/n) = log m − log n
log(mᵖ)  = p·log m
log_b(b) = 1
log_b(1) = 0

Change of base: log_b(x) = log(x)/log(b)
```

### Absolute value

```
|x| = k   →   x = k  or  x = −k
|x| < k   →   −k < x < k
|x| > k   →   x < −k  or  x > k
```

### Complex numbers

```
i = √(−1)    i² = −1    i³ = −i    i⁴ = 1
Conjugate of a + bi is a − bi
(a + bi)(a − bi) = a² + b²
```

### Sequences

```
Arithmetic:   aₙ = a₁ + (n−1)d       sum = n(a₁ + aₙ)/2
Geometric:    aₙ = a₁ · r^(n−1)
```

### Matrices

```
det [a b]
    [c d]  = ad − bc

[a b][e f]   [ae+bg  af+bh]
[c d][g h] = [ce+dg  cf+dh]
```

## Functions

```
Composition:   f(g(x))  — inner first
Inverse:       swap x and y, solve for y
               f(f⁻¹(x)) = x
               f⁻¹ is the reflection of f over y = x

Exponential:   y = a·bˣ           y = a(1 ± r)ᵗ
Compound:      A = P(1 + r/n)^(nt)
```

### Transformations

```
f(x) + k      up k
f(x) − k      down k
f(x + h)      LEFT h
f(x − h)      RIGHT h
−f(x)         reflect over x-axis
f(−x)         reflect over y-axis
a·f(x)        vertical stretch (a > 1)
f(ax)         horizontal compression (a > 1)
```

### Trigonometric graphs

For `y = A·sin(Bx + C) + D`:
```
Amplitude = |A|
Period    = 2π/|B|        (tangent: π/|B|)
Midline   = y = D
```

## Geometry — plane

```
Triangle angle sum:        180°
Exterior angle:            = sum of two remote interior angles
Triangle inequality:       |a − b| < c < a + b

Polygon interior sum:      (n − 2)·180°
Regular polygon each:      (n − 2)·180°/n
Exterior angle sum:        360°
Regular polygon exterior:  360°/n
Diagonals:                 n(n − 3)/2
```

### Areas

```
Rectangle:              lw
Square:                 s²
Triangle:               ½bh
Equilateral triangle:   (s²√3)/4
Parallelogram:          bh
Rhombus:                bh  or  ½d₁d₂
Trapezoid:              ½(b₁ + b₂)h
Circle:                 πr²
Triangle (SAS):         ½ab·sin C
```

### Circles

```
Circumference:    C = 2πr = πd
Area:             A = πr²
Equation:         (x−h)² + (y−k)² = r²

Arc length:       (θ/360)·2πr        radians: s = rθ
Sector area:      (θ/360)·πr²        radians: A = ½r²θ

Central angle    = intercepted arc
Inscribed angle  = ½ intercepted arc
Angle in a semicircle = 90°
Tangent ⊥ radius at the point of tangency
```

### Right triangles

```
Pythagorean:      a² + b² = c²

45-45-90:         x : x : x√2
30-60-90:         x : x√3 : 2x

Triples:          3-4-5   5-12-13   8-15-17   7-24-25   9-40-41

Square diagonal:  s√2
Equilateral height: (s√3)/2
```

## Trigonometry

```
sin θ = opp/hyp      cos θ = adj/hyp      tan θ = opp/adj
csc θ = hyp/opp      sec θ = hyp/adj      cot θ = adj/opp

sin²θ + cos²θ = 1
tan θ = sin θ / cos θ
sin θ = cos(90° − θ)

Law of Sines:    a/sin A = b/sin B = c/sin C

```

## Statistics and probability

```
mean = sum/count          sum = mean × count
Weighted average = Σ(value × weight) / Σ(weights)

range = max − min
IQR = Q3 − Q1

Right-skewed:  mean > median
Left-skewed:   mean < median

More spread → larger SD
Add a constant to all values → SD unchanged
Multiply all values by k → SD × |k|
```

```
P(A) = favorable/total
P(not A) = 1 − P(A)
P(A and B) = P(A)·P(B)              [independent]
P(A or B)  = P(A) + P(B) − P(A and B)
P(A | B)   = P(A and B)/P(B)

Expected value = Σ(value × probability)
```

### Counting

```
Fundamental principle:  multiply choices at each stage
Permutation (order matters):    P(n,r) = n!/(n−r)!
Combination (order doesn't):    C(n,r) = n!/[r!(n−r)!]
n! = n(n−1)...(1),  0! = 1

Overlapping sets:  Total = A + B − both + neither
```

## Rates, percents, and measurement

```
distance = rate × time
Average speed = total distance / total time
Combined work: 1/t₁ + 1/t₂ = 1/t_total,  or  t = ab/(a+b)

percent change = (new − old)/old × 100
Increase by p%: × (1 + p/100)
Decrease by p%: × (1 − p/100)

Direct variation:   y = kx
Inverse variation:  y = k/x  (xy = k)

Simple interest:    I = Prt
Compound interest:  A = P(1 + r/n)^(nt)
```

### Unit conversion

```
1 mile = 5280 ft       1 hour = 3600 s
1 yard = 3 ft          1 kg = 1000 g
1 foot = 12 in         1 km = 1000 m
1 pound = 16 oz        1 L = 1000 mL

AREA converts by the SQUARE of the linear factor:   1 ft² = 144 in²
VOLUME converts by the CUBE of the linear factor:   1 yd³ = 27 ft³
```

## The memorize-first shortlist

If you have limited time, these carry the most weight per item on the ACT:

1. **Slope, distance, midpoint**
2. **Quadratic formula** and the **discriminant**
3. **Special right triangles** and **Pythagorean triples**
4. **Circle area, circumference, and equation**
5. **All the volume formulas** (no reference sheet!)
6. **Equilateral triangle area** `(s²√3)/4`
7. **Similar-figure scaling** — `k`, `k²`, `k³`
8. **SOH-CAH-TOA** and `sin θ = cos(90° − θ)`
9. **Law of Sines and Law of Cosines**
10. **Amplitude `|A|`, period `2π/|B|`**
11. **Permutation vs. combination**
12. **Percent change with the original in the denominator**
13. **Log rules**
14. **Area and volume unit conversion** (square it, cube it)

## How to use this file

Reading it repeatedly produces recognition, not recall. Instead:

1. **Copy it by hand once.** Handwriting is meaningfully better for retention.
2. **Blank-page test weekly.** Write everything you remember without looking.
   The gaps are your study list.
3. **Make cards only for the gaps**, not for everything.
4. **Drill formulas in context.** Knowing `D = b² − 4ac` is useless if you don't
   recognize a "how many solutions" question as a discriminant question.

Because the ACT provides nothing, a formula you half-remember is a question you
lose. Recall must be automatic, not reconstructible.
