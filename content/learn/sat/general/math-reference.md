# Math formulas to know

Bluebook's reference sheet gives the basic area and volume formulas, the
Pythagorean theorem and the special right triangles (listed in
[Format and scoring](learn:sat/general/format-and-scoring#reference-sheet)).
Everything below is not on the sheet, and each line links to the page that
teaches it.

## How to learn them {#how-to-learn}

Reading a formula list builds recognition, not recall. Instead:

1. Once a week, write out as much of this table as you can from memory on a blank page. What you miss is your list for the week.
2. Learn each formula through its page's examples, so you also know when a question calls for it.
3. Recheck the list before each official practice test.
