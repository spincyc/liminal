# Linear equations in one variable

A linear equation in one variable has one unknown, and that unknown is never
squared, under a root or in a denominator: 3(x − 4) = 2x + 5 is one. This is
the base skill for all of Algebra, which is {{fact:sat-math-algebra}} of the
Math section.

## Before you start {#before-you-start}

This page assumes three Grade 8 skills. If a check below goes wrong,
rebuild it with
[lesson 2-1, combining like terms](lessons.html#common-core-math/8/2-1),
[lesson 2-3, distributing](lessons.html#common-core-math/8/2-3) or
[lesson 2-4, multistep equations](lessons.html#common-core-math/8/2-4).

> **Try it.** Solve 3x + 8 − x = 20.
>
> **Answer.** x = 6
>
> Combine like terms: 2x + 8 = 20. Subtract 8: 2x = 12, so x = 6. Shaky?
> [Lesson 2-1](lessons.html#common-core-math/8/2-1).

> **Try it.** Solve 3 − 2(x − 4) = 5.
>
> **Answer.** x = 3
>
> The −2 multiplies both terms inside: 3 − 2x + 8 = 5, so 11 − 2x = 5.
> Subtract 11: −2x = −6, so x = 3. Shaky?
> [Lesson 2-3](lessons.html#common-core-math/8/2-3).

> **Try it.** Solve x/2 + x/3 = 10.
>
> **Answer.** x = 12
>
> Multiply every term by 6: 3x + 2x = 60, so 5x = 60 and x = 12. Shaky?
> [Lesson 2-4](lessons.html#common-core-math/8/2-4).

## Solve {#solve}

The method, in order:

1. Clear fractions: multiply every term on both sides by the least common denominator.
2. Distribute, and combine like terms on each side.
3. Move the variable terms to one side and the numbers to the other.
4. Divide by the coefficient of the variable.
5. Substitute your answer into the original equation.

Write each step on its own line. Most errors in this skill are sign errors
from doing two steps at once, not gaps in knowledge.

> **Example.** Solve (2x − 1)/3 + x/2 = 4.
>
> The denominators are 3 and 2, so multiply every term by 6:
> 2(2x − 1) + 3x = 24.
>
> Distribute and combine: 4x − 2 + 3x = 24, so 7x − 2 = 24.
>
> Add 2, then divide by 7: 7x = 26, so x = 26/7.
>
> Check: (2 · 26/7 − 1)/3 = (45/7)/3 = 15/7, and (26/7)/2 = 13/7. Their sum
> is 28/7 = 4. As a student-produced response, enter 26/7.

> **Try it.** What value of x is the solution to (3x + 1)/4 − x/3 = 2?
>
> **First step.** The denominators are 4 and 3, so multiply every term by
> 12: 3(3x + 1) − 4x = 24. Now finish.
>
> **Answer.** x = 21/5
>
> Distribute and combine: 9x + 3 − 4x = 24, so 5x + 3 = 24.
>
> Subtract 3, then divide by 5: 5x = 21, so x = 21/5.
>
> Check: (3 · 21/5 + 1)/4 = (68/5)/4 = 17/5, and (21/5)/3 = 7/5. Their
> difference is 10/5 = 2.

> **Trap.** A negative in front of parentheses multiplies every term inside:
> 5 − 2(x − 3) = 5 − 2x + 6, not 5 − 2x − 6.

Read the last line of the question before you start. If it asks for x + 4 or
2x, the value of x will be sitting among the choices as a trap. Sometimes you
can reach the asked expression directly.

> **Example.** If 3(x + 4) = 27, what is the value of x + 4?
>
> Divide both sides by 3: x + 4 = 9. You never need x itself (x = 5).

> **Try it.** If 4x − 6 = 18, what is the value of 2x − 3?
>
> **Answer.** 9
>
> 4x − 6 is 2 times 2x − 3, so divide both sides by 2: 2x − 3 = 9. The
> trap choice is x itself, 6.

> **Fails when.** The asked expression isn't a simple multiple of a piece
> of the equation. If 3x + 4 = 19 and the question asks for 2x + 1, there is
> no one-step route; solve for x (x = 5) and then compute 2(5) + 1 = 11.

> **Example.** If x/3 + x/4 = 14, what is the value of x/12?
>
> Combine the fractions: x/3 + x/4 = 4x/12 + 3x/12 = 7x/12.
>
> So 7x/12 = 14, which means x/12 = 2. (Solving first also works: x = 24,
> and 24/12 = 2. The trap choice is 24.)

> **Try it.** If x/2 + x/5 = 21, what is the value of x/10?
>
> **Answer.** 3
>
> Combine the fractions: x/2 + x/5 = 5x/10 + 2x/10 = 7x/10. So 7x/10 = 21,
> which means x/10 = 3. The trap choice is x itself, 30.

With numeric choices, you can backsolve: substitute each choice into the
equation and keep the one that works.

> **Fails when.** The question asks for something other than x (then a
> choice that satisfies the equation is the trap), or the choices are close
> decimals and substitution is slower than solving. Backsolving is a check,
> not a habit.

For a harder version, see [two quantities that change at once](#two-quantities).

## Rearranging formulas {#rearranging-formulas}

To solve a formula for one of its letters, treat every other letter as a
fixed number and use the same steps as above.

> **Example.** An engineer uses S = (m + 4n)/(3t). Solve for n.
>
> Multiply both sides by 3t: 3tS = m + 4n.
>
> Subtract m: 3tS − m = 4n.
>
> Divide by 4: n = (3tS − m)/4.
>
> Check with numbers: m = 2, n = 1, t = 1 gives S = 6/3 = 2, and
> (3 · 1 · 2 − 2)/4 = 1. ✓

> **Try it.** In a soccer league, a team's points per game is
> P = (3w + d)/g, where w is wins, d is draws and g is games played. Solve
> for w.
>
> **First step.** Multiply both sides by g: Pg = 3w + d. Now finish.
>
> **Answer.** w = (Pg − d)/3
>
> Subtract d: Pg − d = 3w.
>
> Divide by 3: w = (Pg − d)/3.
>
> Check with numbers: w = 6, d = 3, g = 12 gives P = 21/12 = 7/4, and
> (7/4 · 12 − 3)/3 = (21 − 3)/3 = 6.

> **Check.** Pick easy values for the other letters, compute the target from
> the original formula, and see whether your rearranged version gives the
> same value. A wrong rearrangement almost never passes this test.

For a harder version, see [a target letter in two terms](#target-in-two-terms).

## Interpret constants {#interpret-constants}

In a context, each number in the equation means something. The constant term
is usually a starting amount, the coefficient of the variable is a rate (an
amount per one unit of the variable), and the other side is a target total.
Say the units out loud: "dollars", "dollars per week", "weeks".

> **Example.** Maya has saved $180 and adds $25 each week. The equation
> 180 + 25w = 530 describes her savings. What does 25 represent, and what
> does the solution represent?
>
> 25 is multiplied by w (weeks), so its units are dollars per week: the
> amount she adds each week.
>
> Solve: 25w = 350, so w = 14. The solution is the number of weeks until
> her savings reach $530.
>
> 180 is the amount she had before week 1; 530 is the savings goal.

> **Try it.** A tank holds 2,400 liters when a pump starts draining it. The
> equation 2,400 − 60m = 900 describes the tank after m minutes. What does
> 60 represent, and what does the solution represent?
>
> **Answer.** 60 is the number of liters the pump drains each minute. The
> solution, m = 25, is the number of minutes until the tank holds 900
> liters.
>
> 60 is multiplied by m (minutes), so its units are liters per minute: the
> pump's draining rate.
>
> Solve: 60m = 1,500, so m = 25. The solution is the time, in minutes, when
> the tank is down to 900 liters.

> **Trap.** A choice that describes a total ("the total she saves in 14
> weeks") when the question asks about a rate, or the reverse. Check the
> units of the number against the units in the choice.

## No or infinite solutions {#no-or-infinite-solutions}

Simplify both sides to the form ax + b = cx + d. Then:

| Condition | Number of solutions |
| --- | --- |
| a ≠ c | exactly one |
| a = c and b ≠ d | none (the x terms cancel and leave a false statement such as 5 = 9) |
| a = c and b = d | infinitely many (both sides are identical) |

> **Example.** In 4(2x − 3) + k = 8x + 5, k is a constant. For what value of
> k does the equation have infinitely many solutions?
>
> Distribute: 8x − 12 + k = 8x + 5.
>
> The x coefficients already match (8 and 8), so the equation has
> infinitely many solutions when the constants match: −12 + k = 5, so
> k = 17.
>
> For any other k the constants differ and there is no solution. This
> equation can never have exactly one solution.

> **Try it.** In 2(3x − 4) + kx = 9x + 1, k is a constant. The equation has
> no solution. What is the value of k?
>
> **Answer.** k = 3
>
> Distribute: 6x − 8 + kx = 9x + 1, so (6 + k)x − 8 = 9x + 1.
>
> No solution needs equal x-coefficients and unequal constants: 6 + k = 9,
> so k = 3, and −8 ≠ 1.

> **Trap.** "No solution" means no value of x works. It does not mean x = 0,
> and it does not mean the answer is "any number".

> **Try it.** How many solutions does 4(x − 2) + 3 = 2(2x − 1) − 3 have?
>
> **Answer.** Infinitely many
>
> Left side: 4x − 8 + 3 = 4x − 5. Right side: 4x − 2 − 3 = 4x − 5. The two
> sides are identical, so every x is a solution.

For a harder version, see [a constant in more than one place](#constant-in-several-places).

## Harder versions {#hard}

The harder questions add structure, not arithmetic: a quantity that starts
late, a target letter in two terms, or a constant in more than one place.

### Two quantities that change at once {#two-quantities}

When one quantity starts late, write both in the same time
variable, count the late one's change from t minus the delay, and write the
comparison the right way round.

> **Example.** At 8:00 a.m. a warehouse holds 900 boxes and ships 15 boxes a
> minute. A second warehouse holds 100 boxes, and starting at 8:10 a.m. it
> receives 20 boxes a minute. How many minutes after 8:00 does the first
> warehouse hold twice as many boxes as the second?
>
> First warehouse after t minutes: 900 − 15t. Second, for t ≥ 10:
> 100 + 20(t − 10).
>
> "The first is twice the second": 900 − 15t = 2(100 + 20(t − 10)) =
> 40t − 200. So 1,100 = 55t and t = 20.
>
> Check: at t = 20 the first holds 600 and the second 100 + 20(10) = 300.

> **Try it.** At 6:00 p.m., parking garage A holds 400 cars, and cars leave
> it at a steady 6 cars a minute. Garage B holds 50 cars; starting at
> 6:10 p.m., cars arrive at it at 3 cars a minute. How many minutes after
> 6:00 p.m. does garage A hold twice as many cars as garage B?
>
> **First step.** Garage A after t minutes: 400 − 6t. Garage B, for
> t ≥ 10: 50 + 3(t − 10) = 3t + 20. Now write the comparison and solve.
>
> **Answer.** 30 minutes
>
> "A holds twice as many as B": 400 − 6t = 2(3t + 20) = 6t + 40. So
> 360 = 12t and t = 30.
>
> Check: at t = 30, garage A holds 400 − 180 = 220 cars and garage B holds
> 50 + 3(20) = 110.

> **Trap.** Writing 20t for the second warehouse, which starts its clock 10
> minutes early, or doubling the wrong side. Each slip gives a different,
> offered answer.

### A target letter in two terms {#target-in-two-terms}

When the target letter appears twice, collect both terms on one side and
factor it out before dividing.

> **Example.** Solve kx + 5 = 2x + m for x.
>
> Collect the x terms on the left and the rest on the right: kx − 2x = m − 5.
>
> Factor out x: x(k − 2) = m − 5.
>
> Divide: x = (m − 5)/(k − 2), which needs k ≠ 2.

> **Fails when.** The factor you would divide by is zero. If k = 2, the
> original equation becomes 5 = m: every x works when m = 5, and no x
> works otherwise. A rearrangement that divides by a variable expression
> must state that it is nonzero.

> **Try it.** A store mixes 4 pounds of coffee beans that cost c dollars in
> all with w pounds of beans that cost $12 a pound. The mixture's cost per
> pound is p = (c + 12w)/(4 + w). Which equation gives w in terms of c and p?
>
> - A) w = (c − 4p)/(12 − p)
> - B) w = (c + 4p)/(p − 12)
> - C) w = (c − 4p)/(p − 12)
> - D) w = (4p − c)/(p + 12)
>
> **First step.** Multiply both sides by 4 + w: 4p + pw = c + 12w. Now
> collect the w terms and factor.
>
> **Answer.** C
>
> Collect the w terms on the left: pw − 12w = c − 4p.
>
> Factor out w: w(p − 12) = c − 4p, so w = (c − 4p)/(p − 12).
>
> Check with numbers: c = 20 and w = 6 give p = 92/10 = 9.2, and
> (20 − 36.8)/(9.2 − 12) = 6. Choice A gives −6.

### A constant in more than one place {#constant-in-several-places}

When one constant sits in both the x-coefficient and the constant term,
matching the x-coefficients can give two candidates; the constant terms
decide which gives no solution. A solution for every value of a constant
makes that constant's term zero.

> **Example.** In x − 2 = k(9kx + 6), k is a constant. The equation has no
> solution. What is k?
>
> Multiply out: x − 2 = 9k²x + 6k. For no solution, the x-coefficients
> must match, so 9k² = 1 and k = 1/3 or k = −1/3.
>
> If k = −1/3, the constant 6k equals −2, so the equation is an identity
> and has infinitely many solutions. Reject that candidate.
>
> If k = 1/3, the equation is x − 2 = x + 2, which has no solution.
> Therefore k = 1/3.

> **Try it.** In k(4kx − 6) = 9x + 9, k is a constant. The equation has
> infinitely many solutions. What is the value of k?
>
> **First step.** Multiply out: 4k²x − 6k = 9x + 9. Now match the
> x-coefficients, then test each candidate.
>
> **Answer.** k = −3/2
>
> The x-coefficients match when 4k² = 9, so k = 3/2 or k = −3/2.
>
> If k = −3/2, the constant −6k equals 9, so the two sides are identical
> and every x is a solution.
>
> If k = 3/2, the equation is 9x − 9 = 9x + 9, which has no solution.
> Therefore k = −3/2.

> **Try it.** In k(x − 3) + 4x = x + c, k and c are constants. There is a
> value of x that is a solution for every value of k. What is the value of
> c?
>
> **Hint.** Which term changes when k changes?
>
> **Answer.** c = 9
>
> Only k(x − 3) depends on k, so the shared solution must make it 0:
> x = 3.
>
> Substitute x = 3: 0 + 4(3) = 3 + c, so 12 = 3 + c and c = 9.
