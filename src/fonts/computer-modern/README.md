# Computer Modern Unicode Serif

CMU Serif 0.7.0 by Andrey V. Panov and the original METAFONT authors.
Upstream: https://cm-unicode.sourceforge.io/
Distribution and license: https://ctan.org/pkg/cm-unicode

These four complete faces were losslessly repackaged from the upstream OpenType
fonts as WOFF2 with `woff2_compress`. Glyphs, naming and font metadata are
unchanged. The SIL Open Font License and copyright notices are in `OFL.txt`.

| File | Face |
| --- | --- |
| `cmunrm.woff2` | Regular |
| `cmunbx.woff2` | Bold |
| `cmunti.woff2` | Italic |
| `cmunbi.woff2` | Bold italic |

The build embeds these fonts in the reading print stylesheet so downloaded
student readings retain their typography offline. No system font installation
or external font service is needed. These fonts are used only for print.
