    What these booklets are worth

    SAT booklets draw fresh questions from the same templates as practice sets and follow the digital test's module lengths, times, and domain counts. The difficulty mix of each module is a practice approximation: the real test chooses Module 2 from Module 1 performance by rules that are not published, so a full-length booklet always gives the harder Module 2. Time yourself honestly, and treat the percentage as practice feedback, not a score prediction.
