# UI review and simplification — 2026-10-08

The owner requested a cold UI review and fixes for clutter, oversized home-page
branding, the visual mismatch between the Liminal banner and SAT/ACT pages,
and navigation across courses, readings, and AP preparation.

## Findings and changes

| Cold-review finding | Delivered change |
| --- | --- |
| The home-page illustration, slogan, principles, and repeated resource sections postponed the first study choices until roughly 775px down a desktop viewport. | A brief introduction and four compact directories lead directly to Courses, Readings, AP prep, and SAT/ACT. The small banner identity remains. |
| AP pages were marked as Test prep, but the destination opened SAT/ACT with no onward AP link. Six competing global destinations mixed resources and activities. | Four primary destinations remain visible on phones and desktop. Course and reading resources appear in contextual navigation, while AP and SAT/ACT retain their own view controls. |
| SAT/ACT used blue, grey, rounded controls under the warm green banner; its mobile test switch overlapped the wordmark. | Preparation pages share the library palette, typography, and control shapes. The test switch stays in its own toolbar in normal flow. The active assessment shell keeps its dedicated test presentation. |
| Practice sets were buried under onboarding, timed-test cards, and empty recommendations. | A short skill drill is the main action. Onboarding, timed tests, optional drill settings, custom sets, and additional tools expand on request. Actionable recommendations remain visible. |
| Reading browse rendered all 180 nights at once, producing a very long phone page. | Weeks are native disclosures; the first or current week opens initially. Search still covers the whole year, reveals matching weeks, and restores disclosure choices when cleared. Returning from a reading opens and focuses that night. |
| Cross-page reading links reset Grade 8/week 12 to kindergarten/week 1. Weekly work itself defaulted to Grade 12 because of build ordering. | Links derive grade, pathway, week, or named course from the current route. Weekly work defaults explicitly to kindergarten and its grade selector runs upward. Advanced reading levels are never presented as equivalent K–12 grades. |

The shared browsing style supersedes the separate blue test-prep direction
recorded in the October 7 design review. It follows the owner's request for a
coherent interface while retaining the compact Liminal banner. Course content,
question selection/scoring, saved progress formats, and assessment presentation
were not redesigned.

## Verification

- An independent cold review covered all 11 entrypoints at desktop and phone
  widths, plus keyboard, dark, and print samples before implementation.
- The full repository gate ran through `node tools/check-all.js`, the exact
  script behind `npm run check`; npm was unavailable in this environment.
  It covers syntax, content admission, a fresh build, canonical headers and
  script order, asset links, and all 859 Node tests.
- A final Chromium scan covered all 11 entrypoints at 1440px and 320px in light
  mode and 390px in dark mode, with no script errors, failed resource loads,
  horizontal document overflow, or primary links shorter than 44px.
- Browser navigation checks followed selected grades between plans, weekly
  lessons, and readings; checked AP weekly-to-course links; and checked the
  direct weekly default. Route tests cover invalid bookmarks and hash changes.
- Reading checks exercised Space to toggle a week, search matches in week 36,
  clearing filters, returning to the current night, and related grade/week links.
- Practice checks exercised SAT/ACT switching, a drill, answering with feedback,
  Save and exit, reload/resume, completion, the report, and saved progress.
  Collapsed forms reveal themselves before programmatic focus or scrolling.
- Print-media checks confirmed shared navigation is hidden and student reading
  and AP copies remain separate from facilitator notes and answer keys.

This is a browser and implementation review, not a screen-reader certification
or new editorial review of educational content. No dependencies were added.
